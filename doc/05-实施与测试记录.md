## 4. 与规划的实现差异

1. 首版选择原生 JavaScript ES Modules，替代原规划 TypeScript + 构建工具，以减少本地运行步骤。运行时零 npm 第三方依赖；Playwright 仅为开发验证依赖。
2. 网页完成结果可播放，导出前 3–5 秒预览仍是 P1 待办，没有伪造预览功能。
3. HTTP API 使用 Node 内置服务器；无需为了少量本地接口引入框架。SSE 每次发送完整快照，重连直接恢复状态。
4. 提交完成文件时使用硬链接确保不覆盖旧目标，当前要求输出文件系统支持硬链接。
5. “保存结果”是极短的最终提交阶段，此时不接受取消；此前的探测、编码和校验阶段支持取消。
6. CLI 批量任务不写网页历史；两者共享转换核心，网页历史仅包含网页提交的任务。
