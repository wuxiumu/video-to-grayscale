在项目目录中执行，页面和 CLI 使用同一套转换核心。

npm run convert -- --input-dir ./test --recursive

npm run convert -- video.mp4 --mode grayscale --audio auto

npm run doctor

默认深度 + 无音频。先运行 npm run setup:depth 安装模型。--mode grayscale 切换普通灰度；--json 获取结构化结果。
